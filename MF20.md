# MF-20

Korg MS-20 filter emulation.

<img src="screenshots/MF-20.png" alt="MF-20 module" height="500">

---

I really like the MS-20 filter — it's got a distinctive throaty sound. The MF-20 is my attempt to bring it to VCV Rack and MetaModule. It emulates both versions:

- **OTA** — the revised MS-20 (late production), based on the LM13600 op-transconductance amplifier. Smooth and open-sounding.
- **Korg35** — the original MS-20, built around Korg's proprietary Korg35 chip. Slightly edgier, with a different distortion character.

Switch between them in the right-click menu. Both self-oscillate cleanly at maximum resonance.

The signal runs through the **HP filter first, then the LP filter** — matching the MS-20's internal routing. Patch the **Total** cutoff input to sweep both filters together as a band or notch, exactly the way the MS-20's shared cutoff modulation works.

---

## Controls

| Control | Description |
|---|---|
| **LP Cutoff** | Lowpass cutoff, log-scaled 20 Hz – 20 kHz |
| **LP Res** | Lowpass resonance; 100% = onset of self-oscillation |
| **HP Cutoff** | Highpass cutoff, same range |
| **HP Res** | Highpass resonance; 100% = onset of self-oscillation |
| **Drive** | Adds saturation and harmonic color. At minimum the filter is clean; turning it up drives the input into soft clipping, getting progressively louder and dirtier. |

The two filters are always independent at the knob level, matching the MS-20 — there is no "link" knob. To sweep them together, modulate the **Total** cutoff input (see below).

## I/O

| Jack | Description |
|---|---|
| **Audio L / R in** | Stereo input; R normalled to L |
| **LP Cutoff CV** | V/oct CV for LP cutoff only; attenuverter scales ±1× |
| **HP Cutoff CV** | V/oct CV for HP cutoff only; attenuverter scales ±1× |
| **Total Cutoff CV** | V/oct CV added to **both** cutoffs at once, preserving the knob spread — the MS-20's shared cutoff-modulation bus. Attenuverter scales ±1×. Sums on top of the per-filter CVs. |
| **LP L / R out** | Stereo lowpass output |

Polyphonic — up to 16 voices.

## Right-click options

**Filter revision**

- **OTA (revised MS-20)** — LM13600-based topology *(default)*
- **Korg35 (original MS-20)** — original Korg35 chip topology; edgier distortion character, the Drive control clips the forward path rather than the resonance feedback

<details>
<summary>Technical notes</summary>

Both modes use a TPT (Topology-Preserving Transform / zero-delay feedback) implementation, discretizing the full second-order system in one step.

**OTA mode** — models the LM13600-based topology analyzed by Stinchcombe (2006). Diode saturation is in the resonance feedback path; piecewise-linear approximation gives a closed-form solution per sample with no Newton iteration. Pre-gain applies √drive amplification with a ±5 V soft-clip threshold before the filter.

**Korg35 mode** — models the original Korg35 chip (C1 = 3.3 nF, C2 = 1 nF, 3:1 ratio → damping constant 8/3). Nonlinearity is in the forward path (input), not the feedback. Asymmetric clipping thresholds (T_pos = 1.0, T_neg = 0.85 normalized) create even-order harmonics matching the hardware's asymmetric resonance behavior described in Stinchcombe §4.

**References**
- Stinchcombe, T. (2006). *A Study of the Korg MS10 & MS20 Filters*
- Huovilainen, A. (2010). *Revised Virtual Analog Models of the MS-20 Filter*, MSc thesis

</details>
