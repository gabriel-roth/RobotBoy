# RobotBoy migration to vcv-panel-gen-redux (v2)

> **For agentic workers:** execute task-by-task with per-task verification. The
> method for every panel task is the proven parity procedure from the v2 tool's
> own RobotBoy fixtures (\~/Dev/vcv-panel-gen-redux/tests/fixtures/robotboy/).

**Goal:** After this branch merges, no file in RobotBoy references or depends on
\~/Dev/vcv-panel-gen (v1). All nine panels are generated by v2 from new-format
specs in `panel-specs/`, with geometry identical to what ships today.

**Scope discovered during exploration (beyond the four originally migrated):**
`onbetap.yaml`, `ondes.yaml`, `yellowjacket.yaml`, `yellowjacket-gold.yaml` are
shipped v1 specs with committed SVGs; `Retours` is a ninth panel, hand-built
like Particules, whose v1 spec exists only in the panel-refactor worktree.

## Ground rules

- Branch: `panel-gen-v2`. Commit per task. Never touch the four pre-existing
  untracked files (Mutable-Beads-manual.pdf, docs/superpowers/plans/2026-07-11-…,
  docs/test-patches.md, screenshots/Retours.png).
- Generation command (house theme comes from `~/.config/vcv-panel-gen/theme.yaml`
  automatically, as with v1):
  `~/Dev/vcv-panel-gen-redux/.venv/bin/python ~/Dev/vcv-panel-gen-redux/panelgen.py panel-specs/<spec>.yaml --out res/<Slug>.svg`
- Verification helpers: `~/Dev/vcv-panel-gen-redux/tests/parity.py`
  (components_of / panel_paths_of / panel_shapes_of / values_paths_of) and
  `~/Dev/vcv-panel-gen-redux/tools/extract_reference.py`.
- **Parity gates.** For the seven v1-generated panels: components exact (≤1e-3)
  AND normalized panel-path/shape/values multisets equal vs the committed SVG
  (byte-identity is NOT expected — v2 formats floats differently). For the two
  hand-built panels (Particules, Retours): component centers exact vs the
  committed SVG / the `mm2px` calls in src/, plus browser-preview review.
- `res/*.preview.*` files are v1 preview artifacts, git-ignored; regenerate or
  ignore, don't commit.
- vcv/res/ is a build-time copy (vcv/Makefile) — never edit it.
- MetaModule PNGs (`metamodule/assets/*.png`): regenerate ONLY for panels whose
  visual source truly changes (Particules, Retours — hand-built → generated),
  via the metamodule-plugin-sdk's SvgToPng.py at the repo's established settings
  (47.44 dpi, panel layer only — confirm invocation in the vcv-to-metamodule
  skill / metamodule docs before running).

## Tasks

1. **Four known panels.** Adapt the four v2 fixture specs
   (\~/Dev/vcv-panel-gen-redux/tests/fixtures/robotboy/{mf20filter,lop,loooop,particules}.yaml)
   into `panel-specs/` (fix asset paths: `lop-logo.svg` already in panel-specs/;
   copy the nine Particules glyph SVGs from the panel-refactor worktree into
   `panel-specs/glyphs/particules/`). Regenerate all four into `res/`.
   Gates: parity for MF20Filter/Lop/Loooop vs the pre-migration committed SVGs;
   Particules centers vs the hand-built original + preview review. Replace the
   hand-built `res/Particules.svg` with the generated one. Update the four spec
   headers (v2 tool paths, no v1 references). Commit.
2. **Onbetap.** New v2 spec from the committed `res/Onbetap.svg` (v1 spec
   documents intent). Full parity gate. Replace SVG, commit.
3. **Ondes.** Same as task 2.
4. **Yellowjacket + Yellowjacket-gold.** Same, two specs, one module; gold is a
   theme-variant panel (inline theme overrides). Verify both SVGs.
5. **Retours.** New v2 spec — mine the panel-refactor worktree's
   `panel-specs/retours.yaml` (v1 format) and `src/` mm2px calls; centers-exact
   gate vs committed hand-built `res/Retours.svg` + preview review. Replace
   SVG. Copy any Retours-specific assets from the worktree if its spec uses
   them. Commit.
6. **Plumbing + docs sweep.**
   - `metamodule/loooop/sync_info_positions.py`: PANEL_GEN → `~/Dev/vcv-panel-gen-redux`;
     drop the v1-commit-version note; run it for Loooop and Lop against the
     regenerated SVGs and confirm `_info.hh` coordinate diffs are zero (or
     within float-format noise — inspect any diff before accepting).
   - Regenerate MetaModule PNGs for Particules and Retours; confirm pixel size
     matches the old PNGs.
   - `panel-specs/README.md`: short v2 workflow doc (generate/check/preview
     commands, pointer to the vcv-panel skill and the v2 repo).
   - Grep the main tree for remaining `vcv-panel-gen` references outside
     docs/superpowers (historical design docs stay as-is): spec headers done in
     tasks 1-5; leave the two src/ provenance comments unless trivially
     updatable; `.gitignore` comment may be updated.
   - Commit.
7. **Final verification.** Regenerate all nine SVGs from the committed specs and
   re-run every parity gate in one script; `make -C vcv` builds (SVGs load);
   summary appended to this doc. Commit.
