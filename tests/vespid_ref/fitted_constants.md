# Vespid fitted constants (Task 1 output)

Generated by `fit_inverter.py`, `wasp_ref.py`, and `gen_halfband.py`
(2026-07-15). Consumed by Task 2 (C++ core) and Task 3 (tests).
All simulation runs: 48 kHz host rate, 8x oversampling, brentq solver.

## 1. Inverter saturator fit (fit_inverter.py)

Asymmetric-tanh closed form fitted to the DC transfer curve of the
DAFx-2022 CD4069 MOSFET model (paper Table 2), solved by bisection of
i_n(vout) == i_p(vout):

```
finv(vg) = vg <= 0 ?  vHi*tanh(-A0*vg/vHi)  :  -vLo*tanh(A0*vg/vLo)
```

| Mode | Supply | op point | A0 | vHi | vLo | rms fit err |
|---|---|---|---|---|---|---|
| Screaming | 12 V | 8.729 V | **17.88** | **3.031** | **8.500** | 0.407 V |
| Tame | 5 V | 3.191 V | **23.44** | **1.708** | **3.105** | 0.188 V |

(Values rounded to 4 significant digits; full precision in the script
output: A0=17.87973, vHi=3.03111, vLo=8.50003 / A0=23.44249, vHi=1.70783,
vLo=3.10480.)

- The rail-clamp constants use the same vHi/vLo (invHi/invLo == vHi/vLo).
- The 12 V rms fit error is 0.407 V, marginally above the plan's 0.4 V
  guideline. The restricted-window fit (|vg| within 80% of the rails)
  was tried per Step 2 and did NOT improve it (window rms 0.426 V), so
  the full-range fit is kept.

### Open discrepancy: inverter operating point vs paper Fig 5

The brief's expected sanity numbers (12 V supply: transition centered
near vin ~5.5-6 V, op point 5-6.5 V) do NOT hold for the Table-2 model
as published: the reconstructed DC curve is correctly shaped (11.99+ V at
vin=0, ~0 V at vin=12, monotonic, soft knees) but its transition sits
near vin = 8.8 V, op point (vout==vin crossing) 8.73 V.

Investigated before fitting, per the brief's instruction:
- Every Table 2 coefficient was verified digit-for-digit against the
  DAFx20in22 paper PDF (read directly), including the negative-valued
  PMOS alpha polynomial (handled as current magnitude via abs(), as the
  brief instructs).
- Alternate sign conventions were tried: raw negative PMOS vgs/vds
  (vgs = vin-VDD, vds = vout-VDD) gives a fully degenerate curve (PMOS
  never conducts); swapping the NMOS/PMOS coefficient sets moves the
  transition to ~3.15 V (equally wrong, opposite side). The mirrored
  convention (PMOS vgs = VDD-vin, vds = VDD-vout) is the only
  non-degenerate, correctly-directioned one, and is kept.
- Conclusion: the published Table 2 coefficients reproduce the paper's
  Fig 5 shape but not its transition location under eqs 33-34 as
  written; presumably the paper's optimizer worked in a slightly
  different parameterization. The fit re-centers on the actual crossing,
  so the fitted A0/vHi/vLo still describe a valid soft-asymmetric
  saturator; only the absolute op-point voltage disagrees. The resulting
  asymmetry (vHi 3.03 / vLo 8.50 at 12 V) is therefore model-derived,
  not measured-hardware-derived. Flagged for revisit if the character
  sounds wrong.

## 2. Rev 1 derived constants (wasp_ref.py)

```
lambda   = A0/(nInv + A0)
wcComp   = 1/sqrt(lambda*kR2)
kC2eff   = R3*C2*wc_int - kR2*wc_int/(2*pi*fPole)
```

| Mode | nInv | kR2 | lambda | wcComp |
|---|---|---|---|---|
| Screaming | 6.70 | 3.70 | **0.72742** | **0.60955** |
| Tame | 4.00 | 1.00 | **0.85423** | **1.08197** |

- **fPole = 80 kHz** (default kept). Swept 60/80/100/120 kHz: Screaming
  self-osc amplitude and frequency are insensitive (amp 2.64-2.67 V,
  freq 714-720 Hz) because the amplitude is rail-bound, not
  damping-bound. Tame constrains the low end. Full-duration (2 s) Tame
  tail sweep with the final committed constants (fc=1000, rho=1,
  criterion < 0.05 V):

  | fPole | Tame tail | verdict |
  |---|---|---|
  | 40 kHz | 1.381 V | FAIL (free-runs) |
  | 50 kHz | 1.358 V | FAIL (free-runs) |
  | 55 kHz | 1.340 V | FAIL (free-runs) |
  | 60 kHz | 0.0114 V | PASS |
  | 80 kHz | 2.34e-12 V | PASS |

  Tame's free-run threshold sits between 55 and 60 kHz; **fPole must
  stay >= ~60 kHz** (context-menu slider floor should respect this),
  80 kHz retained as default. (An earlier revision of this file claimed
  60 kHz fails with a 0.17 V tail — that number came from a shortened
  1 s probe measured mid-decay, not from the committed constants;
  corrected here after review.)
- Screaming makeup = 2.0, Tame makeup = 1.0 (spec Rev 1, updated 2026-07-15
  once the docs review computed the real inter-mode loudness: Tame's raw LP
  is already unity, so its 2.4 makeup was making it \~7.6 dB *louder* than
  Screaming rather than the intended rough parity. Tame makeup is now unity
  and the residual Tame/Screaming gap is left to the user-facing Output
  level menu control rather than the per-mode constants. Makeup is applied
  outside the golden numbers — self-osc amplitude is measured on the raw BP
  state, small-signal responses are raw LP — so this change does not affect
  golden.json).

### Retunes / deviations from the raw plan defaults

- Plan placeholder constants (Screaming A0=25, vHi=5.1, vLo=5.3; Tame
  A0=15, vHi=2.15, vLo=2.25) were replaced by the fitted values above,
  as Task 1 is specified to do. For the record, the plan-default
  Screaming constants self-oscillate at amp 4.42 V / 506 Hz — much worse
  knob tracking than the fitted set.
- No A0 retune was needed for sustain (Screaming self-oscillates) or for
  Tame ring-out with the fitted values at fPole=80 kHz.

## 3. Acceptance criteria results (wasp_ref.py, Step 4)

Measurement methodology note: small-signal probes are synthesized and
measured at the internal (oversampled) rate. The brief's ZOH-hold +
boxcar-average host-rate resampling costs ~2.9 dB of pure measurement
artifact at 15 kHz (input-ZOH sinc + boxcar-decimator sinc) — with it,
the fc=5000/fp=15000 point read -2.58 dB vs theory; at the internal rate
it reads -0.09 dB. Golden numbers must be true filter responses (the C++
tests use proper halfband resamplers), so the internal-rate measurement
is the recorded one. Peak measurements use a 20 mV probe (50 mV is not
small-signal at a +19 dB resonance: ~0.45 V internal swing compressed
the peak reading by 2.5 dB; at 20 mV it matches theory within 0.03 dB).

- **Small-signal linearity (rho=0.3, Screaming): PASS.** All nine
  lp_db points within +/-0.09 dB of the Rev-1 linear theory
  (criterion +/-1.5 dB). Theory: D(s) = s^2 + lam*(H1(s)+kC2eff)*wc*s +
  lam*kR2*wc^2, H_LP = -lam*wc^2*H_in/D with the exact Delta-Y H1(jw)
  and the 22 Hz input HPF.
- **Resonance peak grows with rho: PASS.** -3.68 / +5.70 / +19.12 dB at
  rho = 0 / 0.5 / 0.9 (monotone), each within 0.03 dB of theory; the
  peak sits exactly on the knob frequency (wcComp verified by probing
  800-1200 Hz at rho=0.9).
- **Screaming self-oscillation amplitude: PASS.** amp = 2.66 V on the
  raw BP state (criterion 1.0-8.0 V), bounded by the rail clamp
  (BP swings +/-2.8 V, HP +3.03/-4.88 V), not divergent.
- **Screaming self-oscillation frequency: FAIL (concern, escalated).**
  866 Hz would be needed (>=850); measured **717 Hz** at fc=1000,
  rho=1 — 28% below the knob. Mechanism understood and documented: the
  limit cycle is rail-bounded, so the OTA tanh (c=0.296 at ~2.8 V) and
  the deeply-clipped inverter compress the effective loop gain; the
  describing-function resonance drops to ~0.72*wc0. The designated
  tuning constants cannot fix it: fPole 60-120 kHz moves freq by only
  +/-4 Hz; A0 10-60 moves it 745->682 Hz (raising A0 makes it worse);
  tightening vHi to 2.0 (a 33% fudge of a fitted constant) still only
  reaches 824 Hz while squeezing the osc amplitude toward the 1.0 V
  floor. The droop is a genuine large-signal property of the spec'd
  model (hardware droops too when states pin the rails). Left at the
  spec'd constants; needs a design decision (e.g. rho-dependent wcComp
  correction, or a relaxed criterion). Droop ratio is consistent across
  cutoffs in the rail-bound regime: fc=2000 -> 1415 Hz (0.71), fc=5000
  -> 3437 Hz (0.69). At fc=200 Screaming does NOT sustain (tail 0.054 V,
  freq ratio 1.016 at that tiny amplitude) — matching the spec's
  "self-oscillates for mid/high cutoffs" (H1's pole raises Re H1 at low
  fc); Task 3 self-osc tests should probe fc >= ~500 Hz.
- **Tame rings out: PASS.** Tail amplitude 2.34e-12 V (criterion < 0.05 V)
  at fc=1000, rho=1, fPole=80 kHz — verge-of-oscillation behavior, no
  free-run.

## 4. Halfband FIR (gen_halfband.py, Step 5)

Deviation from the brief: the requested 31-tap remez halfband cannot
meet the stated validation (stopband > 70 dB above 0.295*fs) — a true
halfband is equal-ripple in both bands (band weighting destroys the
zero-tap structure; verified), and 31 taps over the 0.205-0.295
transition yields 52.6 dB. 70 dB needs ~47 taps (Kaiser estimate ~48).
**Primary deliverable is the 47-tap design, which meets both validation
numbers**; the 31-tap variant is included for Task 2 if the cheaper
filter is preferred at reduced attenuation. Both have the exact halfband
structure (even-offset taps forced to 0, center 0.5).

## 5. golden.json semantics

Generated by `python wasp_ref.py` (run from this directory). All values
float; regenerate after any constant change. C++ tests (Task 3) assert
against these within their own tolerances.

| Key pattern | Meaning |
|---|---|
| `lp_db_screaming_fc{FC}_f{FP}` | Small-signal LP gain in dB, Screaming, rho=0.3, knob cutoff FC Hz, probe FP Hz, 50 mV probe, 0.5 s run (steady-state RMS of the 2nd half vs input). Probe generated and response measured at the internal (8x) rate — true filter response, no resampling artifacts. Raw LP state, no makeup, includes the 22 Hz input HPF. |
| `lp_db_screaming_peak_rho{R}` | Same measurement at fc=1000, probe 1000 Hz, **20 mV probe**, rho=R (0.0/0.5/0.9) — resonance-peak growth. |
| `selfosc_screaming_amp` | Screaming, fc=1000, rho=1: sine-equivalent amplitude (sqrt(2)*std, mean removed) of the raw BP state over the last 0.25 s of a 2 s run after a 0.1 s 3 V kick. Volts, pre-makeup. |
| `selfosc_screaming_freq` | Positive-going zero-crossing frequency (Hz) of the same tail. |
| `selfosc_tame_amp` | Same amplitude measurement for Tame — must be ~0 (rings out). |
| `lambda_screaming`, `lambda_tame` | Rev-1 loop-gain factor A0/(nInv+A0) from the fitted A0. |
| `fpole` | Inverter bandwidth (Hz) used for kC2eff (Rev 1 default 80e3). |

Implementation note: `wasp_ref.H1_of_jw` deliberately duplicates
h1_check.py's Delta-Y-Delta math rather than importing it (h1_check.py
runs top-level prints on import); the two were verified numerically
identical.
